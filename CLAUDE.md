# CLAUDE.md

Este repositorio usa `AGENTS.md` como fuente principal de instrucciones para agentes de IA.

Antes de actuar, leer en este orden:

1. `AGENTS.md`
2. `docs/CONSTITUCION.md`
3. `docs/PROGRESO.md`
4. `memory.md`
5. La spec correspondiente en `specs/`

Reglas mínimas:

- No escribir código sin una spec aprobada.
- No inventar colores, tipografías, precios ni datos del negocio.
- No exponer secretos ni acceder a la base de datos desde el cliente.
- No usar autenticación externa.
- Documentar los cambios y mantener `memory.md` actualizado.
